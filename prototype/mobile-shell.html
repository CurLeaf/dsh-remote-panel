移动外壳原型

390 × 844。基线按 lib/client.js 的 SHELL_CSS / MobileBar 复刻；本轮已改触发按钮、新对话标题、右上角新建对话、新对话区鱼标与问候语、会话行 ⋯ 菜单（重命名 / 置顶 / 归档，苹果备忘录式分组：线性图标 + 内缩淡分割线）；抽屉改成按工作区分组（4 组，点标题折叠 / 展开，文件夹图标随折叠换开 / 合，当前会话所在组高亮，搜索时强制展开并显示「命中 / 总数」）；整页固定纯黑底、去掉分割线；移除底部三栏；输入条改成一整块圆角卡片（文字在上，右下两枚圆形按钮：描边「+」与主色「发送」，没有「深度思考 / 智能搜索」胶囊）。点左上角按钮开抽屉，点遮罩关抽屉；点搜索框会撑满页面，左上返回键回抽屉；插件页暂时用 ?tab=plugins 打开。

搜索改成了搜对话内容：输入停 250ms 才发请求，等待期铺三行骨架屏，回来后标题命中在前、纯内容命中在后，内容命中在标题下补一行片段（12px 次级色、单行省略，对齐 DSH 的 searchResultSnippet）。正文来自页面底部的 LOGS 假数据，片段按 240 码位裁剪，与 dsh-session-query-sqlite 的 makeSnippet 同一套规则。
